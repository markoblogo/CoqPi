# CoqPi v0.3.1

This release adds the supervised MN7R Monitor Live bridge for brokerage calls.

## Changes

- Copy a selected client setup from Monitor and apply it in `Settings → Monitor`.
- Sign in with a normal Monitor account; the password is discarded and the token is stored with macOS secure storage.
- Send only bounded finalized `OTHER` speech after explicit permission.
- Show a temporary current client BID/OFFER draft and scrollable opposite-side Monitor market options after a 900 ms debounce.
- Ignore `ME`, partial, and system transcript items and reject stale responses.
- Save to Monitor Draft Inbox only after an explicit click.

## Boundaries

- No automatic message, counteroffer, CRM update, or operational BID/OFFER/TRADE creation.
- No system-audio capture or automatic speaker separation.
- Synthetic checks do not prove real microphone accuracy or live-call latency.

## Installation

Stop any active recording, quit CoqPi, download the Apple Silicon archive and `SHA256SUMS.txt`, verify the checksum, extract the archive, and replace the existing app. Local data remains under `~/Library/Application Support/coqpi`.
