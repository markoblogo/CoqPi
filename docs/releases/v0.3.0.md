# CoqPi v0.3.0

This maintenance release makes the public repository reproducible and removes owner-specific bootstrap data from the current source tree.

## Changes

- Electron 44 and Crawlee 3.18.1.
- Clean dependency audit with reviewed transitive overrides.
- CI-backed `pnpm check` gate.
- Neutral first-run profile that preserves any existing local profile.
- Self-contained deterministic tests that do not depend on ignored personal files.
- Shorter public README, MIT license, security policy, contribution guide, and changelog.

## Installation

Download the Apple Silicon archive and checksum from the GitHub release. Stop any active recording, quit CoqPi, verify the checksum, extract the archive, and replace the existing app. Local data remains under `~/Library/Application Support/coqpi`.
