# CoqPi v0.2.0

## Conversation Controls

- Hold Space in the focused Live window to mark your speech, or use the
  **Говорю я** toggle for long answers and switching to the call app.
- Your original speech remains recorded as `ME` but is excluded from automatic
  and manual answer requests, translation and interlocutor-language changes.
- The other person's question and current suggested answer remain visible.
- Delayed transcript events retain the role assigned to their speech item.
- Interim/final speaker labels survive local persistence and Markdown/TXT export.

This release also includes the preceding conversation-first work: answer-first
Live, per-utterance EN/FR/RU/UK language handling, incremental transcript
checkpoints and saved conversations independent of assistant success.

## Installation

Download `CoqPi-0.2.0-arm64.zip` from the GitHub release, extract it, quit CoqPi
after stopping any active recording, and replace the app in Applications.
The bundle targets Apple Silicon macOS. Local recordings/settings are not
included in the download. Replacing the application does not delete user data.

The app is unsigned and not notarized. macOS may require explicit approval to
open it. Verify the download against `SHA256SUMS.txt`; do not disable system
security globally. Intel macOS builds are not provided in this release.

## Verification

- Targeted speaker, transcript persistence and live-loop regression tests.
- Analyze-recent-transcript regression tests, TypeScript, lint and production build.
- Previously completed synthetic Electron UI checks cover Space, delayed finals,
  the latched toggle, focus loss, editable fields, archive labels and close recovery.
  These are simulated-provider tests, not a live microphone accuracy guarantee.

## Remaining Limits

- Space is local to the focused CoqPi window, not a global hotkey.
- Mark before speaking. Mixed speakers in one uninterrupted speech item cannot
  be separated reliably; the item is conservatively excluded from suggestions.
- Already sent assistant requests cannot be undone by changing the speaker mark.
- There is no raw audio backup or separate system-audio capture. Speech missed
  while STT is unavailable cannot be recovered from the text journal.
- Long noisy calls, real voice attribution and end-to-end latency still require
  user validation.
