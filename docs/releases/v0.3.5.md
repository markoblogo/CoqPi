# CoqPi v0.3.5

## Conversation fixes

- The latest finalized incoming turn is explicitly identified in each Live request.
  Earlier speech is background, not another question to translate or answer again.
- Proposed responses must preserve explicit amounts, deadlines, negations and
  exclusions. Uncertain feasibility calls for clarification, not a forbidden shortcut.
- No extra provider request or model change was introduced.

## Verification

- Full isolated `pnpm check`: 373 tests passed, typecheck/lint/build passed,
  zero known dependency advisories.
- Real synthetic audio via BlackHole and OpenAI: EN -> FR -> EN, three preserved
  transcript segments, correct answer-language switches, Stop and reopen verified.
- Complete answer latency in that sample: 3.5 / 4.9 / 3.1 seconds. The two targeted
  semantic failures did not recur. No universal correctness or latency guarantee.
- User settings, stored key access and existing transcript content were checked
  after installation of the identical-code local candidate.

See the [detailed report](https://github.com/markoblogo/CoqPi/blob/v0.3.5/docs/audits/2026-10-23/V034_BILINGUAL_CHECK.md).
The audio-tested candidate reported 0.3.4; this release changes its version metadata
to 0.3.5 without further application code changes.

## macOS

Apple Silicon application ZIP and SHA-256 checksum are attached. The application
is not notarized. Quit CoqPi before replacing the app in Applications. Keep the
existing Application Support folder to preserve keys, settings and recordings.
